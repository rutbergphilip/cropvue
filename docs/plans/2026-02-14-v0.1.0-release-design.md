# CropVue v0.1.0 Release Design

## Goal

Ship cropvue as a public open-source package on npm and GitHub.

## Decisions

- **GitHub:** `rutbergphilip/cropvue` (personal account, public repo)
- **License:** MIT (already in package.json files)
- **npm scope:** `@cropvue` org (already created)
- **Versioning:** Changesets (already configured, linked packages)

## Scope

### Create GitHub repo and push

- Create `rutbergphilip/cropvue` public repo
- Set `main` as default branch
- Push existing code

### Add missing OSS files

- `LICENSE` — MIT license text with 2026 Philip Rutberg
- `CONTRIBUTING.md` — brief: prerequisites, local dev setup, PR guidelines
- Update root `README.md` — add badges (npm, CI, license), ensure quick start is clear

### Clean up for release

- `.gitignore` — add `full-page.png`, `.playwright-mcp/`, `test-avatar.svg`, `docs/.vitepress/dist/`, `docs/.vitepress/cache/`
- All 3 `package.json` files — add `repository`, `homepage`, `bugs`, `keywords` fields
- Remove stale files from git tracking (full-page.png, .playwright-mcp, test-avatar.svg)

### Version and publish

- Create changeset for minor bump (0.0.1 -> 0.1.0)
- Run `pnpm changeset version` to apply
- Push to GitHub
- Add `NPM_TOKEN` secret to GitHub repo
- Release workflow publishes to npm automatically

### Skipped for v0.1.0

- Code of Conduct
- Issue templates
- Dependabot
- Playground deployment
