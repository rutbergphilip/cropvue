# CropVue v0.1.0 Release Plan

> **For Claude:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** Ship cropvue as a public open-source package on GitHub and npm.

**Architecture:** Monorepo with 3 linked packages (`@cropvue/core`, `cropvue`, `@cropvue/nuxt`) published via Changesets. GitHub Actions handles CI and npm publishing.

**Tech Stack:** pnpm workspace, Changesets, GitHub Actions, npm

---

### Task 1: Clean up .gitignore and remove tracked artifacts

**Files:**
- Modify: `.gitignore`

**Step 1: Update .gitignore**

Add these entries to `.gitignore`:

```
.playwright-mcp/
full-page.png
test-avatar.svg
docs/.vitepress/dist/
docs/.vitepress/cache/
```

**Step 2: Remove tracked artifacts from git index**

Run: `git rm -r --cached .playwright-mcp/ full-page.png test-avatar.svg docs/.vitepress/dist/ docs/.vitepress/cache/ 2>/dev/null; echo done`

Only errors for files that don't exist — that's fine.

**Step 3: Commit**

```bash

git add -u
git commit -m "chore: clean up gitignore and remove tracked artifacts"
```

### Task 7: Version bump to 0.1.0

**Step 1: Create changeset file**

Create `.changeset/release-v0.1.0.md`:

```markdown
---
"@cropvue/core": minor
"cropvue": minor
"@cropvue/nuxt": minor
---

Initial public release of CropVue - headless image cropping for Vue 3 + Nuxt.
```

**Step 2: Apply version bump**

Run: `pnpm changeset version`

This bumps all 3 packages from 0.0.1 to 0.1.0 and generates CHANGELOG.md files.

**Step 3: Commit and push**

```bash
git add .
git commit -m "chore: version packages to 0.1.0"
git push
```

---

### Task 8: Configure NPM_TOKEN and trigger publish

**Step 1: User adds NPM_TOKEN secret**

User must manually add `NPM_TOKEN` to GitHub repo settings:
Settings > Secrets and variables > Actions > New repository secret

**Step 2: Verify release workflow runs**

The push from Task 7 triggers the Release workflow which runs `pnpm changeset publish` to publish all 3 packages to npm.

**Step 3: Verify on npm**

Check:
- https://www.npmjs.com/package/cropvue
- https://www.npmjs.com/package/@cropvue/core
- https://www.npmjs.com/package/@cropvue/nuxt

### Task 9: Create GitHub release

**Step 1: Tag the release**


**Step 2: Create GitHub release from tag**

Use `gh release create v0.1.0 --title "v0.1.0" --notes "Initial public release..."` with highlights from the README features list.
